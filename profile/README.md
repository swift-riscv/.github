# Swift RISC-V

Swift implementation of the RISC-V instruction set architecture — a per-authority organization of [swift-standards](https://github.com/swift-standards), Layer 2 of the [Swift Institute](https://github.com/swift-institute) ecosystem.

## What this is

This organization hosts a single package, following the same discipline as every specification package in the ecosystem: the source document implemented as literally as possible, with parsing, validation, and formatting enforced by Swift's type system. Where several specifications govern one subject, the unifying `swift-*-standard` package lives in [swift-standards](https://github.com/swift-standards).

> Swift RISC-V is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by RISC-V International.

Browse the organization's [repositories](https://github.com/swift-riscv?tab=repositories) for current package locations.

Contributions are welcome via pull request.
